# Maize Yield Prediction (ML + Web UI)

This project provides a web application with:

- Home page (project overview)
- Signup page
- Login page
- Prediction page (protected)

Backend:

- Flask (Python)

Frontend:

- HTML/CSS/Bootstrap + JavaScript

ML:

- A training pipeline + inference code
- Dataset placement instructions in `data/`

## Run

1. Create a virtual environment and install dependencies.
2. Start the Flask server.
3. Open the web UI in your browser.

Detailed steps are included in `backend/README_BACKEND.md`.
